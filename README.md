# RankForge MCP Server 📈🔍🚀

Universal Autonomous SEO Agency, Keyword Research & SERP Intelligence MCP Server for **Cursor, Claude Code, and Windsurf**.

## 🌟 Core Capabilities:
- 🔍 **On-Page SEO Audit:** Comprehensive health check for Title pixel-width, Meta descriptions, H1-H3 hierarchy, OpenGraph, and Twitter Cards.
- 🎯 **Keyword Intent & Difficulty:** Analyze search intent (Commercial, Transactional, Informational), Keyword Difficulty (KD%), and long-tail variations.
- 🗺️ **Sitemap & Robots Generator:** Valid XML sitemaps (`sitemap.xml`) and crawler rules (`robots.txt`) for Next.js, Remix, and static sites.
- 📱 **Google SERP Snippet Simulator:** Exact search result preview with star ratings, breadcrumbs, and JSON-LD schema markup.
